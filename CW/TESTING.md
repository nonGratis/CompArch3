# Тестування та Аналіз Курсової Роботи

## 🧪 Результати тестування

### Збірка проекту:
✅ **УСПІШНО** - Проект зібрано без помилок
- Розмір коду: 176 байт
- Таблиця векторів: 64 байт (0x40)
- Код програми: 112 байт (0x70)

### Аналіз машинного коду:

#### Таблиця векторів (0x08000000):
```
00000000: 20020000  ; SP = 0x20020000 (початок стеку)
00000004: 08000041  ; Reset Handler = 0x08000040 + 1 (Thumb)
00000008: 0800004B  ; NMI Handler
0000000C: 0800004D  ; Hard Fault Handler
...
```

#### Основна функція обчислення (0x08000060):
```assembly
08000060: B5F0        PUSH    {r4-r7,lr}      ; Збереження контексту
08000062: F04F0412    MOV.W   r4, #18         ; X₁ = 18
08000066: F06F0508    MVN.W   r5, #8          ; X₂ = -9 (через MVN)
0800006A: F04F0617    MOV.W   r6, #23         ; X₃ = 23
0800006E: EA4F0565    MOV.W   r5, r5,ASR #1   ; X₂ >> 1 = -5
08000072: EA440405    ORR.W   r4, r4, r5      ; X₁ | (X₂ >> 1)
08000076: F04F0703    MOV.W   r7, #3          ; Лічильник = 3
0800007A: EA4F0464    MOV.W   r4, r4,ASR #1   ; Цикл >> 1
0800007E: 3F01        SUBS    r7, #1          ; Декремент
08000080: D1FB        BNE.N   0x0800007A      ; Повторити якщо ≠0
08000082: F0860601    EOR.W   r6, r6, #1      ; X₃ ⊕ 1
08000086: EA4F0646    MOV.W   r6, r6,LSL #1   ; × 2
0800008A: EBA40406    SUB.W   r4, r4, r6      ; Фінальне віднімання
0800008E: 4620        MOV     r0, r4          ; Результат у r0
08000090: BDF0        POP     {r4-r7,pc}      ; Повернення
```

## 🔍 Пошагова верифікація

### Крок 1: Завантаження початкових значень
- `r4 = 18` (0x12)
- `r5 = -9` (0xFFFFFFF7)
- `r6 = 23` (0x17)

### Крок 2: X₂ >> 1 (арифметичний зсув)
- `r5 = -9 >> 1 = -5` (0xFFFFFFFB)
- Арифметичний зсув зберігає знак

### Крок 3: X₁ | (X₂ >> 1)
- `r4 = 18 | (-5) = -1` (0xFFFFFFFF)
- Побітове АБО: 0x12 | 0xFFFFFFFB = 0xFFFFFFFF

### Крок 4: Результат >> 3 (цикл зсувів)
- `r4 = -1 >> 1 = -1` (перша ітерація)
- `r4 = -1 >> 1 = -1` (друга ітерація)  
- `r4 = -1 >> 1 = -1` (третя ітерація)
- **Результат: -1** (арифметичний зсув -1 завжди дає -1)

### Крок 5: X₃ ⊕ 1
- `r6 = 23 ⊕ 1 = 22` (0x16)

### Крок 6: Множення на 2
- `r6 = 22 << 1 = 44` (0x2C)

### Крок 7: Фінальне віднімання
- `r4 = -1 - 44 = -45` (0xFFFFFFD3)

## ✅ Підтвердження правильності

### Математична перевірка:
```
F = (((X₁ | (X₂ >> 1)) >> 3) - 2 × (X₃ ⊕ 1))
F = (((18 | (-9 >> 1)) >> 3) - 2 × (23 ⊕ 1))
F = (((18 | (-5)) >> 3) - 2 × 22)
F = (((-1) >> 3) - 44)
F = (-1 - 44)
F = -45
```

### Представлення у доповняльному коді:
- **-45 (decimal) = 0xFFFFFFD3 (hex)**
- Перевірка: 0xFFFFFFD3 + 45 = 0x100000000 (переповнення) ✓

## 🏆 Особливості Cortex-M4

### Ефективність коду:
1. **MVN інструкція**: компілятор оптимізував `MOV r5, #-9` як `MVN r5, #8`
2. **Thumb-2 кодування**: використання 32-бітних інструкцій для великих констант
3. **Компактність**: весь алгоритм займає лише 48 байт

### Переваги архітектури:
- Вбудована підтримка арифметичних зсувів
- Ефективна робота з від'ємними числами
- Потужні побітові операції в одному циклі
