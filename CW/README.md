# Курсова робота: Реалізація обчислювального алгоритму на QEMU для STM32F407VG

## 🎯 Мета роботи
Розробити програму для обчислення виразу **F = (((X₁ | (X₂ >> 1)) >> 3) - 2 × (X₃ ⊕ 1))** мовою асемблера ARM, використовуючи QEMU для емуляції процесорного ядра STM32F407VG (Cortex-M4).

## 📊 Початкові умови
- **X₁ = 18** (0x12)
- **X₂ = -9** (0xFFFFFFF7 у доповняльному коді)  
- **X₃ = 23** (0x17)
- Представлення: доповняльний код (two's complement)

## 🔧 Архітектура проекту

### Файли проекту:
- `CW.S` - основний код обчислення формули
- `start.S` - стартовий файл з таблицею векторів переривань
- `lscript.ld` - скрипт компонувальника для STM32F407VG
- `Makefile` - файл збірки проекту

## 🧮 Алгоритм обчислення (згідно з таблицею мікрооперацій)

| №   | Інструкція      | Опис операції                      | Значення   | Hex        |
|-----|-----------------|------------------------------------|-----------|-----------  |
| 1   | `MOV r4, #18`   | Завантаження X₁                    | 18        | 0x12       |
| 2   | `MOV r5, #-9`   | Завантаження X₂                    | -9        | 0xFFFFFFF7 |
| 3   | `MOV r6, #23`   | Завантаження X₃                    | 23        | 0x17       |
| 4   | `ASR r5, #1`    | Арифметичний зсув X₂ вправо на 1   | -5        | 0xFFFFFFFB |
| 5   | `ORR r4, r5`    | Побітове АБО: X₁ \| (X₂ >> 1)      | -1        | 0xFFFFFFFF |
| 6   | `MOV r7, #3`    | Завантаження лічильника зсувів     | 3         | 0x03       |
| 7-9 | `ASR r4, #1` ×3 | Три послідовні арифметичні зсуви   | -1        | 0xFFFFFFFF |
| 10  | `EOR r6, #1`    | Побітове ВИКЛЮЧНЕ АБО: X₃ ⊕ 1      | 22        | 0x16       |
| 11  | `LSL r6, #1`    | Множення на 2 (зсув вліво)         | 44        | 0x2C       |
| 12  | `SUB r4, r6`    | Фінальна операція віднімання       | **-45**   | **0xFFFFFFD3** |

## 📈 Результат обчислення
**F = -45** (0xFFFFFFD3)

### Покрокова перевірка:
1. X₁ | (X₂ >> 1) = 18 | (-9 >> 1) = 18 | (-5) = -1
2. (-1) >> 3 = -1 (арифметичний зсув зберігає знак)
3. X₃ ⊕ 1 = 23 ⊕ 1 = 22
4. 2 × 22 = 44
5. -1 - 44 = -45

## 🏗️ Структура пам'яті та регістрів

### Використані регістри:
- **r4 (Rx)**: зберігає X₁, потім проміжні результати
- **r5 (Ry)**: зберігає X₂
- **r6 (R3)**: зберігає X₃
- **r7 (CT)**: лічильник зсувів
- **r0**: повертає фінальний результат

### Карта пам'яті STM32F407VG:
- **Flash**: 0x08000000 - 0x080FFFFF (1MB)
- **RAM**: 0x20000000 - 0x2001FFFF (128KB)
- **CCM RAM**: 0x10000000 - 0x1000FFFF (64KB)
- **Стек**: початок з 0x20020000

## 🔍 Алгоритм верифікації коректності

### Перевірки згідно з технічним завданням:
1. **Детекція переповнення**: аналіз прапорців APSR після арифметичних операцій
2. **Перевірка нуля в молодшій частині**: виділення та аналіз молодшого байту результату
3. **Нормалізація та перевірка зсуву**: контроль правильності арифметичних зсувів

## 📊 Аналіз дизасемблера

Згенерований файл `firmware_disasm.txt` містить:
- Машинний код кожної інструкції
- Адреси розміщення в пам'яті
- Коментарі до операцій
- Структуру функцій та циклів

### Ключові адреси:
- `0x08000040`: `reset_handler` - точка входу
- `0x08000060`: `compute_formula` - основна функція обчислення
- `0x08000092`: `verify_result` - функція верифікації
- `0x080000A2`: `main_program` - головна програма

- Правильного представлення від'ємних чисел у доповняльному коді
